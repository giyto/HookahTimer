## Why

Первым самостоятельным этапом приложению нужен рабочий экран зала, на котором можно создать схему столов и удобно менять их расположение. Этот фундамент позволит отдельно и последовательно добавить настройки, таймеры и постоянное хранение в следующих OpenSpec changes.

## What Changes

- Заменить шаблонный экран Android-приложения экраном зала на Jetpack Compose и Material 3.
- Использовать `Box` как рабочее поле, а каждый стол отображать отдельным Composable.
- Добавить базовую MVVM-структуру с однонаправленным потоком данных, ViewModel и StateFlow для состояния рабочего поля.
- Поддержать круглое и pill-отображение столов; новый стол получает автоматически сформированное название и круглую форму.
- Добавить режим редактирования зала, в котором пользователь может создавать, перемещать и удалять столы.
- Различать обычное нажатие и drag-жест, ограничивать столы границами рабочего поля и подтверждать удаление.
- Сохранять состояние зала в ViewModel при пересоздании Compose UI в рамках запущенного процесса.
- Добавить unit-тесты расчёта позиции и Compose UI Tests основных действий рабочего поля.
- Не включать в этот change экран настройки стола, проходки, таймеры, просрочку, Room и восстановление после перезапуска процесса — они будут отдельными последовательными changes.

## Capabilities

### New Capabilities

- `hall-layout`: отображение рабочего поля и столов, режим редактирования, добавление, перемещение и подтверждённое удаление столов.

### Modified Capabilities

Отсутствуют: основные спецификации проекта пока не созданы.

## Impact

- Изменятся `MainActivity` и Compose UI модуля `app`; шаблонный `Greeting` будет удалён.
- Появятся базовые domain/presentation/UI модели рабочего поля, ViewModel и StateFlow.
- Потребуются Compose-компоненты рабочего поля и стола, обработка жестов и тесты.
- Постоянное хранилище и новые внешние зависимости, кроме необходимых lifecycle/ViewModel API, в этом change не добавляются.
