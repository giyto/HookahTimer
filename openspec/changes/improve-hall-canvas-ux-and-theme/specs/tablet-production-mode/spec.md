## ADDED Requirements

### Requirement: Блокировка преобразований рабочего пространства
Система SHALL предоставлять явно различимую блокировку текущего viewport, которая предотвращает случайное панорамирование и масштабирование canvas во время обслуживания зала.

#### Scenario: Включение блокировки
- **WHEN** пользователь включает блокировку viewport
- **THEN** система фиксирует текущие масштаб и смещение и визуально показывает закрытый замок

#### Scenario: Жест на заблокированном canvas
- **WHEN** пользователь проводит пальцем или выполняет жест масштабирования на заблокированном canvas
- **THEN** система не изменяет масштаб и смещение рабочего пространства

#### Scenario: Работа со столами при блокировке
- **WHEN** viewport заблокирован и пользователь нажимает на стол в рабочем режиме
- **THEN** система продолжает выполнять переход состояния этого стола по обычным правилам

#### Scenario: Выключение блокировки
- **WHEN** пользователь выключает блокировку viewport
- **THEN** система сохраняет текущий вид и снова принимает жесты панорамирования и масштабирования

#### Scenario: Пересоздание экрана
- **WHEN** экран пересоздаётся в рамках текущей сессии после изменения конфигурации
- **THEN** система восстанавливает состояние блокировки, масштаб и смещение viewport
