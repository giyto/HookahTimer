## Context

Машина состояний уже хранит идентификатор текущей проходки, а `TableTimerPresentation` вычисляет её номер для активного и просроченного стола. `HallTableItem` показывает таймер по центру и название снизу; мотивация и наблюдаемое поведение описаны в `proposal.md` и `specs/table-passage-indicator/spec.md`.

## Goals / Non-Goals

**Goals:**

- Использовать существующее состояние таймера без нового источника истины.
- Добавить компактный индикатор, подходящий для круглого и pill-стола.
- Сохранить единое вычисление номера проходки и доступное описание состояния.

**Non-Goals:**

- Не менять порядок или логику переключения проходок.
- Не сохранять отформатированный индикатор в Room или `HallUiState`.
- Не увеличивать размеры столов и не перемещать индикатор за их границы.

## Decisions

### 1. Индикатор вычисляется из существующей presentation-модели

Текущий номер берётся из `TableTimerPresentation.passageNumber`, а общее количество — из неизменяемого списка настроенных проходок стола. Форматирование `текущая/всего` выполняется строковым ресурсом только при наличии `timerText`.

Добавление отдельного поля в Room или состояния во ViewModel отклонено: это производное значение, которое уже однозначно вычисляется из доменной модели и могло бы рассинхронизироваться после изменения проходки.

### 2. Компактная подпись размещается сверху по центру

Активное содержимое делится на три визуальные зоны: индикатор сверху, таймер по центру, название снизу. Для обеих форм используется короткий формат `1/2`, небольшой размер текста и одна строка. Отдельная внешняя плашка отклонена, потому что она могла бы пересекаться с соседним столом и усложнила бы ограничение координат рабочим полем.

### 3. Доступность использует развёрнутую формулировку

Визуально остаётся компактный формат, а семантическое описание сообщает текущую проходку и общее количество словами через локализованный ресурс. Индикатор получает стабильный test tag, чтобы Compose UI-тесты не зависели от расположения текста.

## Risks / Trade-offs

- [Длинное название конкурирует с новым текстом на круглом столе] → Сохранить одну строку названия с ellipsis и три фиксированные зоны без изменения размера стола.
- [Кнопка удаления в режиме редактирования занимает верхний угол] → Разместить индикатор по центру и оставить короткий формат без дополнительной плашки.
- [Некорректная конфигурация не содержит текущую проходку] → Использовать уже существующую валидацию доменной модели и показывать индикатор только при ненулевом `passageNumber`.

## Migration Plan

1. Добавить локализованные строки и test tag индикатора.
2. Передать текущий и общий номер в активное содержимое стола.
3. Обновить семантические описания и тесты всех состояний.

Откат удаляет только новый визуальный элемент, строки и проверки; данные Room и активные таймеры остаются совместимыми.
